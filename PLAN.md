# JIMI
This is simple engine that is simply ant app

# Engine How it works?
1. create World, you can use NormalWorld
2. create your Acts
   1. ACT can be Main Menu Act (You can use scene, or Simple Image)
   2. Tutorial Act 
   3. Game Act
   4. Loading Screen Act
3. adding concept
   1. Concept of gravity
   2. Concept of food
4. adding structure (Trees, Houses, Streets)
5. add entities to it 
6. apply Concept
